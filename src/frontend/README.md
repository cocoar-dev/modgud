# Frontend

Angular 20 application for Cocoar.Auth

## Getting Started

```powershell
npm install
npm start
```

## Structure

```
frontend/
├── apps/
│   └── auth-app/           # Main authentication app
├── libs/
│   ├── ui/                 # Shared UI components
│   ├── auth/               # Authentication logic
│   └── shared/             # Shared utilities
└── package.json
```

## Technology Stack

- Angular 20
- Nx (monorepo management)
- TypeScript
- TailwindCSS
- RxJS
