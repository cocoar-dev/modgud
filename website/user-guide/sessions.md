# Session Management

Sessions are viewable under **Account > Sessions**.

## What You See

Each session shows:
- **Browser** and version (e.g., Chrome 120)
- **Operating System** and version (e.g., Windows 11)
- **Device Type** (Desktop, Mobile, Tablet)
- **IP Address**
- **Created** — when the session started
- **Last Active** — when it was last used
- **Current** — badge indicating your active session

## Revoking Sessions

### Revoke a Single Session

Click the **X** or **Revoke** button next to any session. The user on that device will be logged out immediately.

### Revoke All Other Sessions

Click **"Logout everywhere"** to revoke all sessions except your current one. Useful if you suspect unauthorized access.

## Admin Session Management

Under **Administration > Users**, admins can:

1. Open a user's profile
2. View their active sessions
3. **Force logout** — revokes ALL of the user's sessions

This is useful for:
- Revoking access when an employee leaves
- Responding to a security incident
- Unlocking a user who is stuck in a bad session state
